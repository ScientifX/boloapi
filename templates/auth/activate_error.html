What can you do?

{% if error_type == "not_found" or error_type == "expired" %}

Register Again

You can register for a new account to receive a fresh activation link:

curl -X POST "{{ app_base_url }}/v1/auth/register" \ -H "Content-Type: application/json" \ -d '{"email": "your.email@example.com"}'
{% elif error_type == "already_active" %}

Reset Your API Key

If you've lost your API key, you can request a reset:

curl -X POST "{{ app_base_url }}/v1/auth/reset" \ -H "Content-Type: application/json" \ -d '{"email": "your.email@example.com"}'

Get an Access Token

If you have your API key, exchange it for an access token:

curl -X POST "{{ app_base_url }}/v1/auth/token" \ -H "Content-Type: application/json" \ -d '{"api_key": "YOUR_API_KEY"}'
