The password reset token you're using is either invalid or has expired. This could happen if:

  • The reset link has already been used
  • More than 1 hour has passed since the reset email was sent

{% elif "strength" in error_message.lower() or "requirement" in error_message.lower() %}

Your new password doesn't meet the security requirements. Passwords must:

  • Be at least 8 characters long
  • Contain at least one uppercase letter (A-Z)
  • Contain at least one lowercase letter (a-z)
  • Contain at least one number (0-9)
{% else %}

An unexpected error occurred while trying to reset your password. This might be due to:

  • A temporary server issue

  • Invalid token format
  • Account status issues

Request a New Reset Link

Start the password reset process again to receive a fresh link:

curl -X POST "{{ app_base_url }}/v1/auth/forgot_password" \ -H "Content-Type: application/json" \ -d '{"email": "your.email@example.com"}'

Or visit: Forgot Password

Remember:
  • Password reset links are valid for 1 hour only
  • Each link can only be used once
  • Requesting a new reset invalidates previous links
