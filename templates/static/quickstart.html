Step 2: Get an Access Token

Exchange your API key for a JWT access token. Tokens expire after {{ token_expiry_minutes }} minutes.

Python Example:

import requests

# Your API credentials
API_KEY = "{{ user_api_key or 'your-api-key-here' }}"
BASE_URL = "{{ base_url }}"

# Get access token
response = requests.post(
    f"{BASE_URL}/v1/auth/token",
    json={"api_key": API_KEY}
)

if response.status_code == 200:
    token_data = response.json()
    access_token = token_data["access_token"]
    print(f"Access token: {access_token}")
    print(f"Token expires in: {token_data['expires_in']} seconds")
    print(f"Your role: {token_data['role']}")
else:
    print(f"Error: {response.status_code} - {response.text}")

Step 3: Make Your First Search

Use the /v1/search/simple endpoint for wildcard-based searches. Available to all authenticated users.

Python Example - Search by Title:

import requests

# Use the access token from Step 2
headers = {
    "Authorization": f"Bearer {access_token}",
    "Content-Type": "application/json"
}

# Search for records with "Murder" in the title
search_request = {
    "filters": [
        {"field": "title", "value": "Murder*"}
    ],
    "logic": "AND",
    "limit": 10
}

response = requests.post(
    f"{BASE_URL}/v1/search/simple",
    headers=headers,
    json=search_request
)

if response.status_code == 200:
    results = response.json()
    print(f"Found {results['count']} results")
    
    # Display first result
    if results['results']:
        first = results['results'][0]
        data = first['data']
        print(f"\nFirst result:")
        print(f"Title: {data.get('title', 'N/A')}")
        print(f"UID: {data.get('uid', 'N/A')}")
        print(f"Subjects: {', '.join(data.get('subjects', []))}")
else:
    print(f"Error: {response.status_code} - {response.text}")

Available Wildcard Patterns:

  • *text* - Contains "text" anywhere
  • text* - Starts with "text"
  • *text - Ends with "text"
  • text - Exact match

Common Search Fields:

  • title - Crime titles (e.g., "Murder", "Kidnapping")
  • subjects - Person names
  • description - Full text descriptions
  • caution - Warning information
  • warning_message - Additional warnings
  • details - Detailed case information
  • remarks - Additional remarks

Step 4: Advanced Search PREMIUM

Use the /v1/search/advanced endpoint for complex queries with multiple operators and grouped conditions.

Python Example - Complex Search:

import requests

headers = {
    "Authorization": f"Bearer {access_token}",
    "Content-Type": "application/json"
}

# Search for high-value fugitives
# Males, age 25-45, reward >= $100,000, title contains "Murder"
search_request = {
    "groups": [
        {
            "condition": "AND",
            "rules": [
                {"field": "sex", "operator": "equals", "value": "Male"},
                {"field": "age_min", "operator": "between", "value": [25, 45]},
                {"field": "reward_max", "operator": "gte", "value": 100000},
                {"field": "title", "operator": "contains", "value": "Murder"}
            ]
        }
    ],
    "group_logic": "AND",
    "limit": 25
}

response = requests.post(
    f"{BASE_URL}/v1/search/advanced",
    headers=headers,
    json=search_request
)

if response.status_code == 200:
    results = response.json()
    print(f"Found {results['count']} matching fugitives")
    
    for item in results['results']:
        data = item['data']
        print(f"\n{data.get('subjects', ['Unknown'])[0]}")
        print(f"  Crime: {data.get('title', 'N/A')}")
        print(f"  Reward: {data.get('reward_text', 'N/A')}")
        print(f"  Age Range: {data.get('age_range', 'N/A')}")
else:
    print(f"Error: {response.status_code} - {response.text}")

Available Operators:

  • equals - Exact match (case-insensitive for strings)
  • contains - Field contains value
  • starts_with - Field starts with value
  • ends_with - Field ends with value
  • gt - Greater than (numeric fields)
  • lt - Less than (numeric fields)
  • gte - Greater than or equal (numeric fields)
  • lte - Less than or equal (numeric fields)
  • between - Between two values (requires array: [min, max])

Numeric Fields for Comparisons:

  • age_min - Minimum age
  • age_max - Maximum age
  • reward_min - Minimum reward
  • reward_max - Maximum reward
  • height_min - Minimum height (inches)
  • height_max - Maximum height (inches)
  • weight_min - Minimum weight (pounds)
  • weight_max - Maximum weight (pounds)

Response Formats

All search endpoints support multiple response formats via the format query parameter:

Available Formats:

  • json (default) - Structured JSON response
  • csv - Comma-separated values
  • txt - Plain text, pipe-delimited
  • xml - XML format

Python Example - CSV Format:

response = requests.post(
    f"{BASE_URL}/v1/search/simple?format=csv",
    headers=headers,
    json=search_request
)

if response.status_code == 200:
    # Save CSV to file
    with open('results.csv', 'w') as f:
        f.write(response.text)
    print("Results saved to results.csv")
Rate Limits & Best Practices

Rate Limits:

  • API endpoints: 10 requests per minute
  • Tokens expire after {{ token_expiry_minutes }} minutes
  • Request a new token before expiration

Result Limits by Role:

  • Basic: Fixed at 25 results per search
  • Premium: Up to 5,000 results per search
  • Admin: Up to 5,000 results per search

Best Practices:

  • Cache tokens and reuse them until expiration
  • Handle rate limit errors (429 status code) gracefully
  • Use specific filters to narrow results
  • Implement exponential backoff for retries
  • Store your API key securely (environment variables, key vault)
