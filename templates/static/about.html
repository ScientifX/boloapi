About Scientifics.io

Who We Are

Scientifics.io provides BoloAPI, a comprehensive, developer-friendly enhancement to the FBI's Wanted API, the programming interface to the FBI's data source of most wanted fugitives and missing persons. Access to the FBI's data is free and available to the public both by web browser and a REST API. However, the data can be sparse and incomplete, and the search options are limited.

We built this platform because accessing this data shouldn't require manual web scraping or endless web page scrolling. Whether you're building a safety app, conducting research, or working in law enforcement, you need reliable, structured data delivered through modern APIs.

We transform raw Wanted API data into cleaner, more searchable records that you can access via BoloAPI. Our platform handles the complex work of:

  • Data Extraction: Automated daily pulls from FBI sources
  • Data Cleaning: Standardized formatting, pruning irrelevant characters
  • Historical Tracking: Maintaining change history and trend analysis
  • Search Infrastructure: Powerful search with boolean logic and filters
  • Developer Experience: Clean JSON responses, comprehensive documentation, JWT authentication

Build public safety features into your applications. From background check services to community safety apps, our API provides the data foundation you need with enterprise-grade reliability.

  • Developer-Friendly: A RESTful API, clear documentation, helpful error messages

Data Source & Accuracy

Our data comes directly from the FBI's Wanted API. We refresh data daily and maintain both current and historical records. While we take extensive measures to ensure data accuracy through validation and cleaning processes, we always recommend verifying critical information directly with law enforcement agencies.
