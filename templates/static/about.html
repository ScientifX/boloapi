About BoloDoc

Who We Are

BoloDoc is a product of Scientifics.io.

The FBI publishes a Wanted persons API -- free, public, and technically accessible. It is also inconsistent, difficult to search, and quietly destructive of its own history. Records disappear without notice. Fields arrive malformed. Search options are limited to what the FBI chose to expose.

We built BoloDoc to fix that.

BoloDoc pulls from the FBI Wanted API daily, normalizes and cleans every record, preserves a complete change history, and exposes the result through a modern REST API with advanced search, multiple export formats, and reliable uptime. If you need to know what the FBI Wanted list looked like on a specific date -- including records that no longer exist -- BoloDoc can answer that question. The native FBI API cannot.

Who We Serve

Developers and Data Engineers

Build on clean, schema-consistent FBI Wanted data without writing your own ETL pipeline. Export to JSON, CSV, Parquet, or XML. Integrate in minutes with copy-paste code examples across five languages. Premium Annual subscribers can pull up to 5,000 records per query -- suitable for data lake ingestion and batch workflows.

Compliance and Security Teams

BoloDoc maintains a historically accurate record of the FBI Wanted list -- including records that have since been removed. For teams with audit requirements or point-in-time verification needs, this is data the live FBI API cannot provide.

OSINT Researchers and Investigators

Search across 30+ fields using boolean logic, range operators, and array field matching. Filter by physical description, known languages, field office, possible countries, and more. Export results in the format your workflow already uses.

Media and Data Journalism

Track trends across the FBI Wanted list over time. Identify patterns in additions, removals, reward changes, and case modifications. Our historical data supports the kind of longitudinal analysis that snapshot APIs cannot.

True Crime Creators and Publishers

Embeddable widgets (coming soon) will let podcasters, bloggers, and social media creators display live FBI Wanted feeds on their sites without writing code. If this use case is relevant to you, contact us -- we are actively building it.

Our Approach

  • Data Integrity First: Every record is cleaned, validated, and versioned before it reaches you. We do the normalization work so you don't have to.
  • Historically Accurate: We treat FBI Wanted data as a slowly changing dataset -- preserving record history rather than overwriting it. What was true yesterday is still queryable today.
  • Developer-First Design: RESTful endpoints, JWT authentication, interactive Swagger docs, and multi-language code examples. We built the API we would want to use.
  • Transparent Pricing: Clear subscription tiers, no hidden fees. Free tier available with no credit card required.

Data Source & Accuracy

Our data comes directly from the FBI's Wanted API. We refresh data daily and maintain both current and historical records. While we take extensive measures to ensure data accuracy through validation and cleaning processes, we always recommend verifying critical information directly with law enforcement agencies.
