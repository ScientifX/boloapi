Core Authentication Files (MUST ADD):
--------------------------------------
router_auth.py
  - Registration endpoint: POST /auth/register
  - Activation endpoint: GET /auth/activate
  - Token endpoint: POST /auth/token
  - Key reset endpoint: POST /auth/key/reset
  - Database helper functions

jwt_utils.py
  - create_access_token() - Generate JWT tokens
  - decode_access_token() - Validate and decode JWTs
  - extract_user_id() - Get user ID from token
  - extract_role() - Get role from token

jwt_auth.py
  - get_current_user_from_token() - Extract user from JWT
  - require_jwt_role() - Dependency for protecting endpoints
  - get_optional_user() - Optional authentication

security_utils.py
  - generate_api_key() - Create secure API keys
  - hash_api_key() - Bcrypt hashing
  - verify_api_key() - Verify against hash
  - generate_activation_token() - Create activation tokens
  - is_valid_email() - Email validation

INTEGRATION STEPS
-----------------

1. Add Dependencies:
   pip install PyJWT==2.8.0 bcrypt==4.1.2

2. Create Database Table:
   psql -U user -d db -f schema_auth.sql

3. Add Core Files to Your Project:
   - Copy router_auth.py to your project
   - Copy jwt_utils.py to your project
   - Copy jwt_auth.py to your project
   - Copy security_utils.py to your project

4. Update app.py:
   import router_auth
   app.include_router(router_auth.router)

5. Update Protected Endpoints (router_search.py, router_etl.py):
   - Import: from jwt_auth import require_jwt_role
   - Change: Depends(require_role(X)) → Depends(require_jwt_role(X))
   - Extract: current_role = current_user["role"]
   
   See router_search_jwt_example.py for detailed examples

6. Set Environment Variable:
   export JWT_SECRET_KEY="your-secret-key-min-32-chars"

7. Test:
   python test_auth.py

MINIMAL INTEGRATION (FASTEST PATH)
-----------------------------------
If you want to get running quickly:

1. Add 4 files:
   - router_auth.py
   - jwt_utils.py
   - jwt_auth.py
   - security_utils.py

2. Run schema_auth.sql

3. Update app.py:
   import router_auth
   app.include_router(router_auth.router)

4. Keep using session-based auth for your existing endpoints initially
   (they'll still work)

5. Gradually migrate endpoints to JWT using the example file

This lets you add JWT auth without breaking existing functionality.
