WHAT WAS BUILT
--------------
A complete, production-ready JWT authentication system for your FBI Wanted API

KEY SECURITY IMPROVEMENTS FROM YOUR ORIGINAL DESIGN
----------------------------------------------------
✓ Secure activation tokens (not predictable user_id in URL)
✓ API keys stored as bcrypt hashes (never plaintext in database)
✓ Time-limited activation tokens (48 hours)
✓ Short-lived JWT tokens (1 hour)
✓ Secure key reset flow
✓ Protection against duplicate registrations
✓ Proper rate limiting (stricter on sensitive endpoints)

THE AUTHENTICATION FLOW
------------------------
1. User registers with email → receives activation link
2. User clicks link → account activated, receives API key
3. User exchanges API key for JWT token → token valid for 1 hour
4. User includes JWT in Authorization header → accesses protected endpoints
5. Token expires → user requests new token with API key

INTEGRATION WITH YOUR EXISTING CODE
------------------------------------
Your existing endpoints in router_search.py need minimal changes:

CHANGE THIS:
  from auth import UserRole, require_role
  current_role: UserRole = Depends(require_role(UserRole.BASIC))

TO THIS:
  from auth import UserRole
  from jwt_auth import require_jwt_role
  current_user: dict = Depends(require_jwt_role(UserRole.BASIC))
  current_role = current_user["role"]
  user_id = current_user["user_id"]

See router_search_jwt_example.py for detailed before/after examples.

WHAT STAYS THE SAME
--------------------
- All your authorization logic (has_role, get_data_field_for_role, etc.)
- Role hierarchy (PUBLIC < BASIC < PREMIUM < ADMIN)
- Result limits per role
- Database queries
- Business logic

Only the authentication method changes (session → JWT).

DATABASE ADDITIONS
------------------
One new table: users
- Stores: email, role, api_key_hash, activation_token, timestamps
- No passwords (API key based)
- Bcrypt hashed keys
- Proper indexes for performance

ENDPOINTS ADDED
---------------
POST /auth/register      - Register new user
GET  /auth/activate      - Activate account with token
POST /auth/token         - Get JWT from API key
POST /auth/key/reset     - Reset lost API key
GET  /auth/              - Auth system info
